# Top Interview 150 — LeetCode Solutions

This repository contains my solutions to **all 150 problems from LeetCode's Top Interview 150 study plan**, implemented in Python. Each solution includes an explanation to help understand the problem-solving approach, algorithm, and relevant data structures.

The goal is to build a strong foundation in Data Structures and Algorithms (DSA) and prepare for technical interviews through consistent practice.
